🔑 备考建议（四军汇总）

  1. 连词辨析是语法根基: 4年17种连词反复考，特别关注bevor/als/indem/um...zu/während
  2. 人文阅读已成趋势: 2026出现康德哲学和人类学，备考须补充文史哲类德语短文
  3. 中国话题深度递增: 从数据介绍→文化深度，需储备中国传统文化德语表达
  4. 词汇不死背: 70%词汇填空考固定搭配，背词必配介词+语境
  5. 写作三段式雷打不动: 描述图表+个人经验+观点/建议，准备模板+数据描述句型
  6. 改错是日常训练: 每句2处错，sich缺失/语序/配价/Kasus是最常考的4类

🚨 三大致命弱点

🔴 致命1：听写 — 74%学生连3分都拿不到▼
  1. 语音-拼写脱节：长元音/短元音区分，ä/ö/ü拼写，-er/-en/-e词尾频繁错
  2. 复合词不会拆：Kindertageseinrichtung这类长词直接放弃
  3. 节奏不适：3遍朗读模式(正常→分节→全文)，短期记忆要求高
  4. 虚词失分：der/die/das/den/dem+词尾-n/-m/-r最易漏

对策：每周2次专项听写：练变元音+复合词；慢速→常速递进；逐词检查错因

🟠 致命2：语法词汇 — 35%权重的分水岭▼
  1. 介词搭配是硬伤：C部分约70%考固定搭配(sich vorbereiten auf, verzichten auf等)
  2. 连词辨析不扎实：A部分必考weil/wenn/als/bevor/indem
  3. 完形两头难：B部分20题需理解上下文+辨别语法
  4. 改写+改错暴露系统漏洞

对策：背词必配介词；连词做对比表；每周1次改错+1次改写专项

🟡 致命3：写作 — 看似简单陷阱多▼
  1. 结构散：不按3要点组织，写到哪算哪
  2. 句型单调：全篇ich denke/man kann，缺从句和衔接词
  3. 词数不达标：150-180词写不够或超太多
  4. 数据描述差：图表题不会描述趋势和比较

对策：背3套模板(描述/经验/观点)；练数据表达句式；每次写后数词数
